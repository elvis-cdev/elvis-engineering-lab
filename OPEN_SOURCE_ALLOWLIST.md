A repository may be added only after Elvis explicitly approves its full `owner/repository` name and contribution scope. Before proposing a contribution, review the project's `CONTRIBUTING` guide, code of conduct, license, issue discussion, and security policy where available.

## Approval record format

For each approved repository, record:

- Repository: `owner/repository`
- Approved scope: specific areas or issue types
- Restrictions: any files, workflows, or actions that are off-limits
- Approval date: `YYYY-MM-DD`
